# Obsidian Vault — NotifySync

Coffre Obsidian du projet. Pour l'utiliser :

1. Ouvrir Obsidian
2. **File → Open vault → Open folder as vault**
3. Sélectionner ce dossier (`obsidian/`)

## Contenu

- `memory.md` — alimenté par `../memory.sh` (notes datées)
- `.obsidian/` — config locale du vault (versionnée, minimale)

## Conventions

- Notes longues : créer un `.md` à la racine du vault
- Brouillons rapides : passer par `../memory.sh "ma note"`
- Liens internes Obsidian (`[[note]]`) bienvenus
