# Hindsight

Rétrospectives post-tâche. Une entrée = un fichier `YYYY-MM-DD-titre.md`.

## Format d'une entrée

```markdown
# YYYY-MM-DD — Titre court

## Contexte
Quelle tâche, quel objectif, quel point de départ.

## Ce qui a marché
- ...

## Ce qui a coincé
- ...

## Actions
- [ ] Suivi concret à faire
```

L'index global est `hindsight.md` — y ajouter un lien vers chaque nouvelle
entrée.
